# Overview

A basic API that responds with a greeting message when called.

# Personas

- Developer — tests the API and confirms it's working.

# Features

- Call the API and get back a "Hello, World!" message.
- Access the API through a simple web address.
- See the response in JSON format.
- Confirm the API is running and responding correctly.
- Use the API as a starting point for building more features later.
